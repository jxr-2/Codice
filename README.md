# Codice

Codice es una aplicación web pensada para centralizar toda la información de una campaña de D&D 5e en un solo lugar. El objetivo del proyecto es ofrecer una herramienta simple y organizada para que un Director de Juego pueda preparar, administrar y consultar el contenido de su mundo sin depender de múltiples documentos o aplicaciones.

Actualmente el proyecto incluye:

* **Fichas de personaje**, con gestión individual e integración con el grimorio.
* **Grimorio**, para consultar y asignar hechizos.
* **Diario**, donde registrar sesiones y acontecimientos de la campaña.
* **Bitácora**, destinada a almacenar información del mundo, personajes, lugares y cualquier elemento narrativo.
* **Mapas**, para organizar material visual de la campaña.
* **Canvas**, un espacio libre para realizar esquemas o tomar notas rápidas.

## Estado del proyecto

Codice se encuentra en desarrollo activo. Gran parte del trabajo actual está centrado en mejorar la experiencia de uso, la estructura de la aplicación y la integración entre los distintos módulos antes de incorporar nuevas funcionalidades.

## Objetivos

El proyecto busca convertirse en una herramienta completa para la preparación y dirección de campañas, incorporando gradualmente funciones como:

* Constructor de encuentros.
* Gestión avanzada de NPCs.
* Organización del mundo por regiones y ciudades.
* Sistema de objetos mágicos.
* Automatización de tareas repetitivas.
* Mejoras en la edición y navegación del contenido.

## Tecnologías

* HTML
* CSS
* JavaScript (Vanilla)

Actualmente no utiliza frameworks, con el objetivo de mantener una estructura ligera, fácil de entender y sencilla de mantener.
